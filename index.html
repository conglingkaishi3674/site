数据浏览

把每天的市场公开数据收进来、按固定口径解读。第一个是股指期货持仓（中金所每日盘后公布的前 20 名会员持仓，俗称「龙虎榜」）：看多单、空单的日度增减，判断机构在场内的头寸是在加还是在减。

—
选一个品种，点「刷新」加载
怎么读这份数据：「净持仓 = 前 20 席位持买单量合计 − 持卖单量合计」。机构常年拿空单对冲手里的现货，所以常态是净空；净空持续收窄、甚至翻多 → 套保意愿下降、开始主动做多；净空扩大、创出阶段新高 → 加码看空。单看一天意义有限，要连着几天看方向。
⚠ 席位数据是该期货公司全部客户的合并持仓（各类机构、大户、散户都在里面），不能直接读成「某家机构看空」；数据盘后公布，天然滞后一个交易日。
怎么读这份数据：龙虎榜是交易所每个交易日盘后披露的「当日异常波动个股 + 买卖前五席位」。这里按标的列出上榜个股，点开任意一只看它上面每个席位买了多少、卖了多少；席位按性质分四类 —— 机构专用（公募、社保、保险等共用的机构通道）、北向（沪深股通）、游资（知名活跃席位，括号里是市场给的外号）、拉萨·散户（东方财富拉萨系列，散户情绪指标）。切到「按席位排行」可以把当天同名席位的买卖跨标的合计，看谁的手最重。
⚠ 三个要留意的点：①「机构专用」不是某一家机构，同一只票上常有多条互相买卖，要看合计净额；②席位外号会漂移（换席位、分仓是常态），看席位实际行为比看外号可靠；③上榜本身是「异常波动」的结果、不代表方向，净买入大也可能是承接别人的抛盘，要结合位置和量能一起看。
怎么读这份数据：四块 —— ①两市成交额（沪市 + 深市，近一年）：看当前量能处在什么位置、是放量还是缩量；②大盘资金流：把全市场成交拆成 超大单 / 大单 / 中单 / 小单 四档净额，超大单 + 大单 = 主力净额，看的是"谁在买、谁在卖"；③北向 / 南向：沪深港通双向的成交额；④当日成交额前 50：钱最集中在哪里。
⚠ 三个口径上的实话：① 资金分档是全市场口径，不是北向的 —— 北向资金根本没有「大单流入流出」这个数据，沪深港通自始至终只披露成交额与持股，从不提供 L2 级大单拆分，2024-08 起连实时净买入都取消了；② 北向 / 南向给的是成交额（买 + 卖 合计），不是净买入，别当方向读；③ 南向个股成交榜拿不到 —— 数据源未购买该接口权限，连前十都取不到，所以南向只做总量、不做个股榜。
